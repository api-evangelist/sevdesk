Enshrined objects should not be modifiable. Status Quo: In sevDesk system version 1.0 it is possible to directly set and unset / change the value of the property enshrined for Invoice, Voucher, CreditNote and CheckAccountTransaction. This is already not possible in sevDesk-Update 2.0.
